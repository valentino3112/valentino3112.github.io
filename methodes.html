1. Tableau Build / Run / TCO
  1. Lister chaque coût et noter son unité : une fois (€), par an (€/an), par mois (→ × 12), par utilisateur / capteur / bâtiment.
  2. Classer : Build = mise en place, une seule fois (matériel, installation, développement, configuration, tests, audit, formation initiale) ; Run fixe = récurrent indépendant du volume (maintenance, licences annuelles, salaires d'exploitation, abonnement fixe, support) ; Run variable = proportionnel au volume.
  3. Calculer le Run année par année : Run fixe + coût unitaire × volume de l'année. Ajouter les événements (extension, renouvellement, maintenance supplémentaire) à la bonne année.
  4. TCO = Build + Σ Run sur la période demandée. Présenter aussi le cumul par année pour voir quand une solution devient moins chère.
  5. Point d'équilibre (Run constants) : Build1 + n × Run1 = Build2 + n × Run2 → n = ΔBuild / ΔRun.
  6. Conclure : chiffres + horizon + critères non financiers (flexibilité, compétences, sécurité, dépendance au fournisseur, trésorerie).

Pièges : salaire annuel sur une durée en mois (proratiser) ; abonnement mensuel (× 12) ; coût « au-delà de X » (seuil strict : 30 000 n'est pas « au-delà » de 30 000) ; renouvellement du matériel (classé en Run dans le cours, « remplacement en fin de vie ») ; ne pas oublier la maintenance des postes ajoutés.

Message du cours à placer : « une décision qui augmente le coût initial peut réduire fortement le coût global ».

2. Compte de résultat prévisionnel → CAF
LigneComment la calculer
CAclients × prix (+ frais ponctuels × nouveaux clients). Pour un projet d'économies : économies réalisées.
− CVcoût unitaire × volume ; commissions = % du CA concerné
− CFcharges fixes décaissées (salaires, loyers, licences, maintenance…)

CAFrésultat net + amortissements

Pièges

  • L'amortissement n'est pas décaissé : il diminue le résultat (donc l'IS) puis on le rajoute pour la CAF. Ne jamais mettre l'amortissement ET l'investissement dans les flux.
  • Formation passée en charges : pas d'amortissement ; c'est une charge de l'année où elle est faite (souvent l'année 0).
  • Résultat négatif : entreprise existante et bénéficiaire → économie d'IS (IS négatif) ; start-up sans autre activité → IS = 0. complément report des déficits possible si demandé.
  • Les frais financiers ne vont pas dans les flux servant à la VAN (le taux d'actualisation rémunère déjà les capitaux) complément.
  • Taux d'IS non donné : l'écrire comme hypothèse (25 % dans ce cours).

  1. Écrire les flux nets année par année (convention : flux en fin d'année ; investissement initial en A0).
  2. Cumuler pour le délai : année où le cumul devient positif, puis interpolation : (n − 1) + manque / flux de l'année n. Convertir en mois (× 12) et jours (× 30).
  3. Coefficients (1 + i)−t au millième ; flux actualisés à l'euro près.
  4. VAN = Σ flux actualisés (A1…An) − I0 ; IP = Σ flux actualisés / I0.
  5. Interpréter : VAN > 0 / IP > 1 → rentable ; comparer ; liquidité (délai) vs rentabilité (VAN) ; durée de vie.

Pièges

  • BFR = variation : on met chaque année l'augmentation du BFR, pas son niveau. S'il passe de 40 000 à 65 000, le flux est −25 000.
  • BFR récupéré ou non en fin de période : suivre l'énoncé ; s'il ne dit rien, l'écrire comme hypothèse (le cours n'en parle pas).
  • Valeur résiduelle nette d'IS ou non : si un taux d'IS est donné et que le bien est amorti, la plus-value (prix − VNC) est imposée. Si les flux sont donnés « tout faits », on ajoute la VR telle quelle.
  • Flux déjà nets donnés par l'énoncé : ne pas réappliquer l'IS.
  • « Début d'année 4 » = fin d'année 3 en toute rigueur ; la plupart des corrigés le placent dans la colonne A4. Indiquer son choix.
  • Le délai du cours est calculé sur flux non actualisés.
4. Plan de financement
  1. Ressources : ressources propres (apports des associés, fonds propres), subventions, emprunts (année où ils sont versés), CAF de chaque année.
  2. Besoins : investissements (Build et extensions), variation du BFR, remboursements d'emprunt (si donnés).
  3. Flux net = ressources − besoins ; flux nets cumulés année après année.
  4. Lire le tableau : un cumul négatif = trésorerie négative = le plan n'est pas finançable en l'état. Le montant manquant = le cumul le plus négatif.
  5. Proposer des solutions : emprunt (avec frais financiers), investisseurs, subvention, étalement des investissements, réduction du BFR (délais clients/fournisseurs), architecture moins capitalistique (cloud).

Pièges : la CAF peut être négative (année de perte) → elle diminue les ressources ; ne pas mettre le résultat net à la place de la CAF ; ne pas oublier le BFR de démarrage ; l'emprunt ne s'ajoute qu'une fois (l'année où il est encaissé).

Rentabilité (le projet crée-t-il de la valeur ?), financement (avec quelles ressources ?) et trésorerie (a-t-on l'argent à chaque instant ?) sont trois questions différentes : un projet rentable peut être infinançable.

5. Check-list anti-pièges avant de rendre
  • ☐ Unités homogènes (€ / k€, mois / an).
  • ☐ Amortissements dans le résultat, investissements dans les flux, jamais les deux dans les flux.
  • ☐ Formation : charge, pas d'amortissement.
  • ☐ IS : taux donné ? économie d'IS si perte (entreprise existante) ?
  • ☐ BFR en variation ; récupération finale ?
  • ☐ Valeur résiduelle : nette d'IS ? dans la dernière année.
  • ☐ Seuil de rentabilité : CF avec amortissements ; arrondi au client supérieur.
  • ☐ Délai : interpolation, réponse en années + mois.
  • ☐ VAN : signe, unité, phrase d'interprétation.
  • ☐ Hypothèses écrites noir sur blanc quand l'énoncé est ambigu.
6. Rédiger une conclusion d'examen

Structure en 4 temps (5–6 lignes) :

  1. Résultat chiffré : « Le projet A a une VAN de 353 231 € et un IP de 1,35… »
  2. Interprétation : « …il couvre le coût des capitaux de 8 % et crée 0,35 € de richesse par euro investi. »
  3. Comparaison / nuance : liquidité vs rentabilité, durée de vie, risque, sensibilité aux hypothèses.
  4. Décision argumentée + critères non financiers (valeur perçue, sécurité, flexibilité, compétences).

Formules utiles : « le projet est rentable mais pas finançable en l'état », « la rentabilité n'est pas qu'une affaire de CA et de résultat », « la valeur créée justifie-t-elle le coût ? ».
